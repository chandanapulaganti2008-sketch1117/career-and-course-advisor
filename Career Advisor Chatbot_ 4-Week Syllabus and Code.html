Career advisor chatbot: 4-week build syllabus

A week-by-week plan with starter code for each week's data and deliverable. It fits a solo builder or a team of two. Click the three dots beside a week to view, copy or download that week's code.

In scope for v1

  • Single-page chat UI
  • Small API server (FastAPI or Express)
  • Claude API with an advisor system prompt
  • Catalog of about 20 careers and 100 courses
  • Keyword or embedding search over the catalog
  • In-memory sessions, thumbs up/down, summary export

Out of scope for v1

  • User accounts and login
  • Resume parsing
  • Job listings or job-board integration
  • Payments or enrollment
  • Mentor matching
  • Multi-language support and voice

Conversation flow

  1. Welcome
  2. Intake questions
  3. Profile summary (user confirms)
  4. 3 career matches
  5. User picks one
  6. Skill gap and course path
  7. Follow-up Q&A
  8. Summary export

Weekly syllabus and code

Targets and risks

Success targets

  • Intake completion above 70%
  • Thumbs up above 70% of ratings
  • Users who reach a course recommendation
  • Click-through on course links
  • Feedback from 20 to 30 pilot users

Main risks and fixes

  • Invented or outdated courses: recommend only from the catalog and keep a last-updated field
  • Generic advice: make the bot cite the user's own answers
  • Salary claims: keep ranges approximate and link to sources
